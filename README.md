# AllTrans

AllTrans is an Android app translation project that translates text inside other apps at runtime.

It was originally published as an open-source project and is now kept as a public project page without source code in this repository.

## What It Does

- Translates app text from one language to another at runtime.
- Works through the Xposed/LSPosed module ecosystem.
- Lets users choose source and target languages.
- Lets users select which installed apps should be translated.
- Supports per-app translation behavior for apps that need custom handling.

## Android Support

AllTrans targets modern Android devices while preserving compatibility with older supported Android versions from the original project.

## Project Status

This repository is kept as the public landing page for AllTrans.
